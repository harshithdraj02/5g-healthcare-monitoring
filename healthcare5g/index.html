📑 Technical Architecture & Mathematical Formulation

1. End-to-End Latency Formulation

For an alert packet travelling from the wearable sensor gateway to the clinician screen, latency is formulated as the sum of its deterministic and random components:

L = L_q + L_radio + L_transport + L_proc + L_dl + 1[lost] · L_retx

Key parameters:

  • L_q: Queueing delay at the shared cell radio resource (discrete M/G/1 queue model).
  • L_radio: Air-interface transmission time interval: 10 ms (4G), 5 ms (5G eMBB), 1.5 ms (5G URLLC).
  • L_transport: Transport delay (log-normal): Median 30 ms (4G) vs 22 ms (eMBB) vs 2 ms (MEC edge).
  • L_proc: Execution time: 5 ms + Exp(mean 8 ms) in Cloud vs 3 ms + Exp(mean 2 ms) on MEC Edge.
  • 1[lost] · L_retx: Retransmission penalty: Packet loss 1% in 4G vs 0.001% in URLLC.

2. Adaptive EWMA Anomaly Detector Formulation

For each patient and signal x(t), personal baseline μ(t) and variance σ²(t) are tracked using Exponentially Weighted Moving Averages:

μ(t) = μ(t-1) + α [x(t) - μ(t-1)], z(t) = [x(t) - μ(t-1)] / σ(t)

Where α = 1/1800 (memory of ~30 minutes). A sample is flagged if |z| > 4.0 (for Heart Rate) or z < -4.0 (for SpO₂). An alert is confirmed only when at least 8 of the last 10 samples are flagged, suppressing transient motion artefacts.
